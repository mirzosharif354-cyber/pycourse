# Pycourse — Flask + SQLAlchemy backend

Полноценный бэкенд на Flask и SQLAlchemy (без flask_login — аутентификация
сделана вручную через подписанную cookie-сессию Flask и хеширование паролей
через `werkzeug.security`).

## Что внутри

- `app.py` — Flask-приложение: все API-маршруты, аутентификация, раздача видео.
- `models.py` — модели SQLAlchemy (пользователи, уроки, тесты, задачи, чат).
- `static/` — фронтенд (index.html, admin.html, pupil.html, chat.html, app.css, api.js).
- `uploads/videos/` — сюда сохраняются видео, загруженные учителем с компьютера.
- `pycourse.db` — база данных SQLite (создаётся автоматически при первом запуске).

## Установка и запуск

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Сайт откроется на **http://127.0.0.1:5000**

При первом запуске база данных создаётся автоматически и заполняется
демо-данными:

- Учитель: `admin@pycourse.tj` / `admin123`
- Ученик: `pupil@pycourse.tj` / `pupil123`

Своих учеников создаёт только учитель — в разделе «Ученики и рейтинг»
в admin.html.

## Как устроена аутентификация (без flask_login)

1. Пароли никогда не хранятся в открытом виде — только хеш
   (`werkzeug.security.generate_password_hash` / `check_password_hash`).
2. После успешного `/api/login` id пользователя кладётся в подписанную
   cookie-сессию Flask: `session['user_id'] = user.id`.
3. Декоратор `login_required(role=...)` в начале каждого защищённого
   маршрута сам проверяет сессию и роль — учитель это или ученик.
4. `/api/logout` просто очищает сессию.

## Основные эндпоинты API

| Метод | Путь                              | Кто          | Что делает |
|-------|-----------------------------------|--------------|------------|
| POST  | `/api/login`                      | все          | вход |
| POST  | `/api/logout`                     | все          | выход |
| GET   | `/api/me`                         | все          | текущий пользователь |
| GET   | `/api/lessons`                    | все          | список уроков (у ученика — с пометкой completed) |
| POST  | `/api/lessons`                    | учитель      | новый урок (JSON со ссылкой ИЛИ multipart с файлом видео) |
| DELETE| `/api/lessons/<id>`               | учитель      | удалить урок |
| POST  | `/api/lessons/<id>/complete`      | ученик       | отметить урок пройденным (+10 баллов) |
| GET   | `/api/tests?lesson_id=`           | все          | тесты урока |
| POST  | `/api/tests`                      | учитель      | новый тест |
| POST  | `/api/tests/<id>/submit`          | ученик       | ответить на тест (+15 баллов при первом верном ответе) |
| GET   | `/api/tasks?lesson_id=`           | все          | задачи урока |
| POST  | `/api/tasks`                      | учитель      | новая задача |
| GET   | `/api/students`                   | учитель      | список учеников |
| POST  | `/api/students`                   | учитель      | создать ученика (имя, email, пароль) |
| PUT   | `/api/students/<id>/password`     | учитель      | сбросить пароль ученика |
| DELETE| `/api/students/<id>`              | учитель      | удалить ученика |
| GET   | `/api/rating`                     | все          | таблица лидеров |
| PUT   | `/api/me`                         | все          | изменить своё имя / email (логин) / пароль |
| POST  | `/api/lessons/<id>/watch`         | ученик       | отметить видео урока просмотренным (открывает тест/задачи) |
| GET/POST | `/api/chat/teacher`, `/api/chat/ai` | ученик | переписка с учителем / ИИ |
| GET   | `/api/chat/threads`               | учитель      | список учеников, кто писал |
| GET/POST | `/api/chat/admin/<pupil_id>`   | учитель      | переписка с конкретным учеником |

## Функции интерфейса (кабинет ученика)

- **Последовательная блокировка уроков** — следующий урок открывается только после прохождения текущего.
- **Тест с пересдачей** — при неверном ответе можно нажать «Попробовать снова», баллы начисляются только за первый верный ответ.
- **Гейтинг по видео** — тест и задачи скрыты, пока видео не досмотрено до конца (событие `ended`), это фиксируется на сервере (`WatchedVideo`).
- **Редактор кода в стиле VS Code** — для каждой задачи: тёмная тема, живая подсказка по функциям в коде, живая проверка синтаксиса (без запуска), кнопка «Запустить код» реально выполняет Python в браузере через Pyodide.
- **Настройки профиля** — и ученик, и учитель могут сменить своё имя, email (логин) и пароль (с подтверждением текущего пароля).
- **Чат** — отдельные каналы с учителем и с ИИ-помощником; ИИ отвечает сразу же (заглушка `ai_reply()` в `app.py` — замените на вызов настоящей модели, когда будет готово).

## Что стоит поменять для боевого использования

- Заменить `SECRET_KEY` в `app.py` на свой случайный секрет (переменная окружения `SECRET_KEY`).
- Перейти с SQLite на PostgreSQL/MySQL при росте нагрузки (достаточно поменять `SQLALCHEMY_DATABASE_URI`).
- Подключить настоящий ИИ вместо заглушки `ai_reply()` в `app.py`.
- Запускать не через `python app.py` (dev-сервер), а через gunicorn/uwsgi за nginx.
- Ограничить `MAX_CONTENT_LENGTH` и добавить, при необходимости, ограничение по IP/логированию.
